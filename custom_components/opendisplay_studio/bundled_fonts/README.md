# Fonts that come with OpenDisplay Studio

These fonts are drawn by the renderer and offered in every font field. They are free
software under the SIL Open Font License 1.1; the text of the license of each family is
next to its files.

| Family | Files | Source | License |
|---|---|---|---|
| Carlito, a free font with the metrics of Calibri | `Carlito-Regular.ttf`, `Carlito-Bold.ttf` | <https://github.com/googlefonts/carlito> | `OFL-Carlito.txt` |
| Atkinson Hyperlegible, made for legibility by the Braille Institute | `AtkinsonHyperlegible-Regular.ttf`, `AtkinsonHyperlegible-Bold.ttf` | <https://github.com/googlefonts/atkinson-hyperlegible> | `OFL-AtkinsonHyperlegible.txt` |

| Inter, a clean font for screens (SemiBold) | `Inter-SemiBold.ttf` | <https://github.com/rsms/inter> | `OFL-Inter.txt` |
| IBM Plex Mono, for numbers that line up (Medium) | `IBMPlexMono-Medium.ttf` | <https://github.com/IBM/plex> | `OFL-IBMPlexMono.txt` |
| Barlow Condensed, narrow and strong (Bold) | `BarlowCondensed-Bold.ttf` | <https://github.com/jpt/barlow> | `OFL-BarlowCondensed.txt` |

`ppb.ttf` (Poppins Bold) and `rbm.ttf` (Roboto Mono Bold) come with `odl-renderer`.
